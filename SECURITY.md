# Security Policy

## Supported Versions

Petty is currently an early-stage prototype. Security fixes are applied to the
latest code on `dev` and then promoted to `master`; older commits and local
builds are not supported as separate release lines.

## Reporting a Vulnerability

Do not open a public issue for a vulnerability that exposes private data,
allows unintended code execution, or creates a meaningful macOS security risk.

Use GitHub's private vulnerability reporting or Security Advisory feature for
this repository. Include:

- the affected commit or version;
- macOS and hardware details;
- clear reproduction steps;
- expected and actual behavior;
- impact and any known workaround.

Please avoid accessing data that is not yours, disrupting other systems, or
publishing exploit details before the maintainer has had a reasonable chance to
investigate.
