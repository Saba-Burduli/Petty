# Storm Trooper

Imported from **Free RETRO FPS/Side scroll Pixel 2D "Storm Trooper"** by W_K_Studio.

Source: https://whiteknightstudios.itch.io/old-school-fps-8d-trooper-v3
License stated on source page: Creative Commons Zero v1.0 Universal.

Notes:
- Source archive: `storm trooper.rar`.
- Petty uses the east-facing direction from the source pack.
- Source animation mapping: `IDLEING` -> idle, `WALKING` -> walk, `SHOOTING IDLE` -> attack, `FALLING` -> sleepy/dead slot.
- Black source backgrounds were converted to transparency for desktop rendering.
