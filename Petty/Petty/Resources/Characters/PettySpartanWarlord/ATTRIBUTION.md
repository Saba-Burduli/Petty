# Spartan Warlord

Original 2D indie-style character generated for Petty as a broad Spartan warrior archetype.

The local `docs/media/Iconic-games/Kratos-gow` images were not copied into this character pack and are not redistributed as runtime assets. This pack uses newly generated transparent PNG animation frames authored for Petty.

Runtime animations:
- Idle: breathing, helmet/head bob, blink frames.
- Walk: alternating legs, arm/shield motion.
- Attack: spear thrust.
- Sleep: resting pose.
