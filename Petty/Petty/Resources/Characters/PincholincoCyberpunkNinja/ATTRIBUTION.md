# Cyberpunk Ninja

Source: https://pincholinco.itch.io/ninja-character-sprite

Notes:
- Source file used: `neon-ninja.svg`.
- The source pack includes 8 platformer/sidescroller animations. Petty maps idle, run, and attack frames directly; the source roll/dodge frames are mapped into Petty's sleepy/dead slot because the source pack does not provide a sleep animation.
- Original source files were used during import and are not required at runtime.
