# Surge

Source: https://github.com/alemart/opensurge

Official project page: https://opensurge2d.org/

Imported files:
- `images/players/surge.png`
- `sprites/players/surge.spr`

Petty import notes:
- Frames were cropped from the official 64x64 player sprite sheet using the frame indices in `sprites/players/surge.spr`.
- `animation 15` -> `Frames/Idle`
- `animation 1` -> `Frames/Walk`
- `animation 3` -> `Frames/Attack`
- `animation 4` -> `Frames/Sleep`

License notes:
- The Open Surge official website says the engine includes ready-to-use game assets under Creative Commons licenses.
- `sprites/players/surge.spr` lists Alexandre Martins as author and MIT as the sprite definition license.
- Imported PNG frames are cropped from the original sheet and renamed into Petty's frame sequence layout.
