# Code of Conduct

Petty should be a constructive, technically focused project where contributors
can participate without harassment or hostility.

## Expected Behavior

- Be respectful and specific when discussing code, design, and decisions.
- Assume good intent while still asking for evidence and clear reasoning.
- Accept feedback without personal attacks.
- Respect creators, licenses, privacy, and intellectual property.
- Keep public project spaces safe and relevant to the work.

## Unacceptable Behavior

Harassment, discriminatory language, threats, doxxing, sexualized attention,
spam, and deliberate disruption are not acceptable in project spaces.

## Enforcement

Maintainers may edit or remove content, close contributions, or restrict
participation when this code is violated. Report conduct issues privately using
the repository owner's contact options on GitHub. Do not disclose sensitive
personal information in a public issue.

Maintainers will review reports in good faith and protect reporter privacy as
far as reasonably possible.
